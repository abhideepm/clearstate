# JetBrains Mono Fonts

ClearState app uses JetBrains Mono fonts for the timer and UI elements.

## Required Files

Download the following font files from the JetBrains Mono GitHub repository:
- https://github.com/JetBrains/JetBrainsMono/releases

Required files:
- assets/fonts/JetBrainsMono-Regular.ttf (weight: 400)
- assets/fonts/JetBrainsMono-Bold.ttf (weight: 700)

## Installation

1. Download JetBrainsMono-Regular.ttf and JetBrainsMono-Bold.ttf
2. Place them in the assets/fonts/ directory
3. The fonts are configured in pubspec.yaml
